Internal tool

Shear Pin Tools

Shear Pin Tools is a small command-line program that the channel's operator runs on their own computer. It signs in to the Shear Pin channel's own YouTube account with Google OAuth and does four jobs for that one channel. It is not a public service: nobody else can sign in, and it never touches another channel or account.

JobWhat it doesGoogle API used
Report Reads the channel's own views, watch time, average view duration and audience retention, and writes a private weekly report for the operator. YouTube Analytics API reports.query; YouTube Data API channels, videos, playlistItems (read)
Comments Lists new comments on the channel's own videos, including those held for review, and counts the audience's votes for the next episode. YouTube Data API commentThreads.list, comments.list
Reply Shows a draft reply first. A reply is posted only after a person has read and approved that exact text. No automated or bulk comments. YouTube Data API comments.insert
Upload Uploads the channel's own finished episodes with their title, description, thumbnail, English captions and playlist. Every upload is shown as a dry run first and is sent only on an explicit command. YouTube Data API videos.insert, thumbnails.set, captions.insert, playlistItems.insert

Google user data

The tool works only with the Shear Pin channel's own data. It does not sell, share or transfer YouTube or Google user data, does not use it for advertising, and deletes stored comment text, commenter names and IDs within 30 days.

Shear Pin Tools' use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
