The tool

Shear Pin Tools is a command-line program that runs on the channel operator's own computer. It reads the Shear Pin channel's own statistics and comments, posts replies after a person approves them, and uploads the channel's own videos with their thumbnails, captions and playlist entries. It uses YouTube API Services.
