Shear Pin Tools

Shear Pin Tools is the private app the Shear Pin channel (@ShearPinFiles) uses to manage its own YouTube account. Only the channel's operator uses it, signed in with the channel's own Google account; it never accesses any other channel or account. It reads the channel's own videos, statistics and analytics, and the public comments left on its videos (commenter name, channel ID and comment text). It uses this data only to report on the channel, to read and reply to comments, and to publish the channel's own videos.

Shear Pin Tools uses YouTube API Services. By using it you agree to the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy.

Sharing

We do not sell, share or transfer YouTube or Google user data, and we do not use it for advertising or to train AI models. Shear Pin Tools' use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

Data is kept only on the operator's own computer, never on a shared server. Comment text and commenter names are deleted within 30 days. Access can be revoked at any time at security.google.com/settings/security/permissions. If you commented on a Shear Pin video and want our copy deleted sooner, write to us and we will delete it within 7 days.

This website

This website sets no cookies and runs no scripts, analytics or advertising. It is hosted on GitHub Pages, which may log technical information such as IP addresses for security (GitHub Privacy Statement).
