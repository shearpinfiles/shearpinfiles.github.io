  • It reads the channel's own statistics and comments, posts replies a person has approved, and uploads the channel's own videos.

What Shear Pin Tools is

Shear Pin Tools is an internal command-line tool used only by the operator of the Shear Pin YouTube channel (@ShearPinFiles). It runs on the operator's own computer. It reads the channel's own statistics and comments, posts replies that a person has reviewed and approved, and uploads the channel's own finished videos. It is not offered to other users, and no one else can sign in to it.

Shear Pin Tools uses YouTube API Services. When the operator connects the tool to YouTube, it shows links to this Privacy Policy and the Terms of Use before the Google sign-in; connecting means agreeing to both.

Google user data we access

When the channel owner signs in with Google, the tool asks for the following permissions (OAuth scopes). It uses each one only for the purposes listed.

PermissionWhat the tool does with it
youtube.upload Uploads the channel's own finished episodes (videos.insert) with their title, description, tags, category, language and scheduled publish time, and sets the thumbnail of a video it has just uploaded (thumbnails.set).
youtube.force-ssl Lists the channel's own videos and the comments and replies on them (channels.list, playlistItems.list, videos.list, commentThreads.list, comments.list); posts a reply only after a person approves the exact text (comments.insert); adds the English caption file to a video it has just uploaded (captions.insert); adds that video to the channel's own playlist (playlistItems.insert).
yt-analytics.readonly Reads the channel's own views, watch time, average view duration and audience retention (reports.query for the signed-in channel only).

The data involved is therefore: the channel's own video list and metadata, the channel's own statistics and analytics reports, and the public comments other people have left on the channel's videos, including the commenter's display name, channel ID, comment text, like count and time. The tool never edits or deletes existing videos, comments, captions, ratings or playlists, and it never reads any other channel's private data.

How we use it

  • To produce private reports on the channel's performance for the channel operator.
  • To list new comments for the operator to read, and to count audience votes for the next episode.
  • To draft replies. Every reply is shown to a person first and is posted only after that person approves the exact text. The tool does not post automated or bulk comments.
  • To upload the channel's own videos, together with their thumbnail, captions and playlist entry. Each upload is first shown as a dry run and is sent only on an explicit command from the operator.

Shear Pin Tools' use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. We do not use Google user data for advertising, we do not sell it, and we do not use it to develop, improve or train generalised artificial-intelligence or machine-learning models.

Sharing and transfer

We do not sell, share, rent or transfer YouTube or Google user data to anyone. No third party, advertiser, data broker or analytics service receives it. Reports stay with the channel operator. The only exception would be where the law requires disclosure.

Storage and retention

DataWhere and for how long
OAuth access and refresh tokens On the operator's own computer only, in a file readable only by the operator's user account. Kept until access is revoked or replaced by a new sign-in. Never written to logs, URLs or shared files.
Comment text, commenter display names and commenter channel IDs (comment lists, vote counts, reply drafts) On the operator's own computer only. Deleted automatically after 30 days: every time the tool reads comments, statistics or votes it also deletes these records once they are older than 30 days. Vote records older than 30 days keep only the totals per option, with no names or text.
IDs of comments already seen (so that only new comments are listed) Refreshed from YouTube on every run; deleted if not refreshed within 30 days.
Channel statistics and analytics reports On the operator's own computer only, while access remains authorised; the tool confirms this every time it runs. Reports contain the channel's own numbers and no information about any viewer or commenter. After 30 days, video titles, channel and video IDs and the written summary are removed from each report; only channel-level numbers (subscribers, views, analytics totals) remain.
Record of replies posted On the operator's own computer only. After 30 days only the date and a one-way fingerprint remain, so that the same reply is never posted twice; comment and reply IDs are removed.
Upload progress While an upload is in progress, the tool keeps its upload session address locally so that an interrupted upload can resume. It is deleted when the upload finishes. The video ID and playlist entry ID of a finished upload are removed after 30 days; only a note that the episode was uploaded remains.

No Google user data is stored on any server or in any cloud database operated by us.

Information on devices

Shear Pin Tools stores the files described above only on the operator's own computer. It does not place, read or recognise cookies or similar technologies on anyone else's device, and it does not collect device identifiers.

Revoking access and deletion

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Revoking access makes the stored tokens unusable immediately. After revocation the operator deletes the token file, and all remaining locally stored data obtained from YouTube, including reports, is deleted within 30 days at the latest.

If you have commented on a Shear Pin video and want any copy of your comment held by the tool deleted sooner, write to the address in Contact; we will delete it within 7 days. Deleting a comment on YouTube itself is done on YouTube.

YouTube and Google

Shear Pin Tools uses YouTube API Services. By using Shear Pin Tools you agree to be bound by the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy (https://policies.google.com/privacy).
